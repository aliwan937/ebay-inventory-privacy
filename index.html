Personal eBay inventory service — privacy notice

Purpose: this service is intended for the operator’s own eBay listing management. It is independent of Crosslist. Data: the local application is intended to store authorized listing details, images or image URLs, marketplace identifiers, and connection tokens on the operator’s computer. This HTTPS relay transiently handles the eBay authorization code and state. It does not store eBay passwords or OAuth tokens. Cloudflare processes the HTTP requests used to operate the relay. Notifications: account-deletion messages, their raw signed payloads and receipt times are stored in a private Cloudflare D1 inbox until the local processor verifies them and confirms completion. An unverified notification is not authority to delete data. Retention and control: the operator can revoke this application in eBay account settings and remove its local credentials and data. Verified deletion notifications must be processed by the local backend before it resumes account operations. No sale of data, advertising profiles, or analytics scripts are implemented by this relay. The operator must review this notice against the completed local application before enabling production access.
